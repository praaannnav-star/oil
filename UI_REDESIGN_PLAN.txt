3. SESSION: LOGIN / LOGOUT REDESIGN + WORKERS AUTH
--------------------------------------------------------------------------------
UI (views/Login.js):
  - Two modes toggled by env/config: DEMO (persona grid, current behavior) and
    LIVE (username+password form, forgot-password link stub).
  - Session card in header replaced by avatar menu: profile, role, active
    project context, "Sign Out" with confirm; idle-timeout warning modal (20min).
Backend contract (Workers):
  POST /api/auth/login     {username,password} -> {jwt,refresh,user} (D1 users,
                           bcrypt-hashed passwords; demo personas seeded)
  POST /api/auth/refresh   {refresh} -> {jwt}
  POST /api/auth/logout    {refresh} -> revoke row in D1
Client (services/auth.js):
  - Store jwt in memory + refresh in httpOnly-style keyed IDB (never localStorage).
  - fetch wrapper adds Authorization: Bearer, auto-refresh on 401 once,
    logout-and-redirect on refresh failure.
  - RBAC: allowedRoutes move server-side (JWT claim); client keeps UI-only guard
    (existing router.js logic preserved as convenience, not security).
Reviewer identity fix: review.js uses Auth.getUser() (audit item Serious#6).

5. IMAGES / EVIDENCE PIPELINE (Cloudinary)
--------------------------------------------------------------------------------
Flow: capture(file input, capture=environment)
  → canvas downscale max 1600px + JPEG q0.82 (js/utils/image.js NEW)
  → stage blob in IndexedDB store 'evidenceQueue' {id,reportId,blob,meta}
  → if online: POST /api/evidence/sign {reportId,mime} → signed params
  → PUT directly to Cloudinary → POST /api/evidence/confirm {publicId}
  → thumbnail URL stored on report; gallery uses Cloudinary transforms.
Offline: queue persists; sync.js flushes queue before reports (dependency order).
UI changes: EvidenceViewer gets upload-progress chips + retry-on-fail states;
            Field Capture step 4 shows real thumbnails from staged blobs
            (fixes audit Broken-evidence finding); EXIF date/GPS read via
            createImageBitmap metadata where available, else manual geo tag.

8. LLM MANAGING REPORTS (Workers AI)
--------------------------------------------------------------------------------
Endpoints (all schema-constrained JSON out, temperature 0):
  POST /api/extract      transcript → structured event
                         {discipline,activity,assetTag,qty,unit,start,end,status,
                          blocker,date} — nulls allowed, NEVER invented values
                         (fixes audit fabrication finding). Heuristic fallback
                         (current code) used offline/degraded mode; UI labels
                         source ("AI" vs "Rules").
  POST /api/summarize    {projectId} → daily digest text for Overview
                         "What changed since yesterday?" (replaces hardcoded
                         block Overview.js:101-127 with derived truth).
  POST /api/delay-cause  blocker text → normalized cause enum (feeds Execution
                         Memory tables from real data instead of static arrays).
Prompt hygiene: system prompt pinned in worker/src/prompts.js; every LLM field
carries {value, source:"llm"|"rules"|"user", confidence} provenance triple;
review drawer displays provenance so planners see what AI touched (audit
Explainability finding). All LLM output lands in review queue — never
auto-applied to schedule (state.txt §14 principle).

11. DEPLOYMENT (Cloudflare)
--------------------------------------------------------------------------------
Layout:
  /                    existing static PWA (Pages) — untouched structure
  worker/              NEW: src/index.js (router), src/routes/{auth,projects,
                       reports,reviews,evidence,surveys,classify,llm}.js,
                       src/prompts.js, schema.sql, wrangler.toml
wrangler.toml sketch:
  name="oil-bridge-api" main="src/index.js" compatibility_date="..."
  [[d1_databases]] binding=DB name=oil-field-db
  [vars] CLOUDINARY_CLOUD=..., DEMO_MODE=0, ENABLE_LEAFLET=0
  secrets: CLOUDINARY_API_KEY/SECRET, JWT_SECRET (wrangler secret put)
D1 core tables: users, sessions(refresh), projects(+classification+geo),
  activities, field_reports, extractions(provenance), matches, reviews,
  surveys(+templates), evidence(public_id), audit_events(seq,prev_hash,payload_hash),
  stats_cache. Audit chain verified by nightly Worker cron + /api/audit/verify.
Client switch: api.js gains ApiHttp adapter behind existing service method
  names; useMock=false routes through fetch with retry/backoff; IDB remains
  offline cache + write-behind queue (sync.js extended to drain evidence +
  survey queues). CORS: same-zone route /api/* via Pages _redirects proxy →
  no CORS headaches, one origin.
Deploy steps: wrangler d1 execute --file=schema.sql → deploy worker → set
  secrets → Pages deploy static → smoke script (login→capture→approve→audit).
Windows: update start-server.bat unchanged for dev; add deploy-cf.bat calling
  npx wrangler commands. Rollback = redeploy previous Pages commit + worker
  version pin (`wrangler rollback`).

13. RISKS & MITIGATIONS
--------------------------------------------------------------------------------
R1 Workers AI JSON drift ....... schema validation + retry-once + rules fallback;
                                 provenance triple makes bad fields visible.
R2 Whisper latency on 2G ....... cap recordings at 60s; show progress; typing
                                 fallback always visible.
R3 Cloudinary cost/abuse ....... signed uploads only, per-user rate limit,
                                 max 5 photos/report, transform cache.
R4 JWT in vanilla JS ........... short-lived access (15m) + rotating refresh;
                                 no tokens in localStorage; logout revokes D1 row.
R5 Leaflet CDN dependency ...... default OFF; Phase A embeds are the shipped map.
R6 Scope creep vs SIH demo ..... phase gates: each P# ends with working jury
                                 script run (README §2-min flow must pass).
R7 Offline conflict edits ...... last-write-wins + audit event; conflicts never
                                 silently drop (banner lists merged items).
